# ESOFT — тестовые задания

Репозиторий содержит решения трёх заданий.

## Задание 1 — Дом на HTML и CSS

Веб-страница с домом, созданным средствами HTML и CSS.

- Основание дома — прямоугольный HTML-блок.
- Крыша — CSS-треугольник, созданный с помощью `border`.
- Окно — круг с `border-radius: 50%`.
- Дымоход, дверь, солнце, облака и земля — HTML-элементы со стилями CSS.
- Адаптивность для небольших экранов — медиазапрос `@media`.

Запуск: откройте `index.html` в браузере.

[Открыть задание 1](https://github.com/SemenLipikhin/ESOFT_1_task)

## Задание 3 — Проверка скобочной последовательности

Функция `isValidBrackets` проверяет правильность последовательности круглых, квадратных и фигурных скобок с помощью стека.

- Время: `O(n)`.
- Дополнительная память: `O(n)`.
