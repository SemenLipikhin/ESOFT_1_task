# Дом на HTML и CSS

Учебное задание ESOFT: веб-страница с домом, нарисованным средствами HTML и CSS.

## Запуск

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере.

## Реализация

- Основание дома — прямоугольный HTML-блок.
- Крыша — CSS-треугольник, созданный с помощью `border`.
- Окно — круг с `border-radius: 50%`.
- Дымоход, дверь, солнце, облака и земля — HTML-элементы со стилями CSS.
- Адаптивность для небольших экранов — медиазапрос `@media`.

Внешние библиотеки и изображения не используются.
