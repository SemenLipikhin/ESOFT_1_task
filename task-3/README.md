# Задание 3 — Проверка скобочной последовательности

## Описание

Функция `isValidBrackets(str)` проверяет правильность последовательности круглых `()`, квадратных `[]` и фигурных `{}` скобок.

Для проверки используется стек:

1. Открывающие скобки добавляются в стек.
2. При встрече закрывающей скобки проверяется последняя открывающая скобка.
3. Если стек пуст или типы скобок не совпадают, функция возвращает `false`.
4. После обработки всей строки функция возвращает `true`, только если стек пуст.

Пустая строка считается правильной последовательностью.

## Запуск тестов

Требуется Node.js.

```bash
node brackets.test.js
```

## Сложность

- Время выполнения: `O(n)` — каждый символ обрабатывается один раз.
- Дополнительная память: `O(n)` — в худшем случае стек содержит все открывающие скобки.
