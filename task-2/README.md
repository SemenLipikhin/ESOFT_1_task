# Задание 2 — глубокое копирование объекта

Реализация находится в `deepClone.js`. Она использует `WeakMap` для отслеживания уже скопированных объектов, поэтому корректно обрабатывает циклические ссылки и повторное использование одной ссылки в нескольких свойствах.

## Запуск

Требуется Node.js 18 или новее. Из этой папки выполните:

```bash
node deepClone.test.js
```

## Что поддерживается

- Вложенные объекты и массивы.
- Циклические ссылки и общие ссылки между свойствами.
- `Date`, `RegExp`, `Map`, `Set`.
- `ArrayBuffer`, `SharedArrayBuffer`, `DataView` и типизированные массивы.
- Обёртки примитивов, объекты ошибок и пользовательские прототипы.
- Собственные строковые и Symbol-ключи, неперечисляемые свойства и дескрипторы.

## Ограничения JavaScript

Функции сохраняются по ссылке: универсально скопировать функцию вместе с её лексическим окружением (closure) средствами JavaScript невозможно. `WeakMap`, `WeakSet` и `Promise` также сохраняются по ссылке, поскольку их внутреннее состояние нельзя восстановить стандартными средствами.

## Пример

```js
const original = { user: { name: "Alex" } };
const copy = deepClone(original);

copy.user.name = "Sam";
console.log(original.user.name); // "Alex"
```
